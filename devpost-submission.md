# Title

AI Basics Glassbox

## One-line Summary

A browser-based RAG debugger that lets beginners see chunking, vector-style retrieval, prompt assembly, cited answers, and hallucination risk in one local demo.

## Problem

Beginners often learn AI through chat boxes that hide the most important mechanics. They may hear terms like embeddings, vector search, RAG, grounding, and hallucination, but they do not get to see how those pieces change an answer.

## Solution

AI Basics Glassbox is an interactive learning app that makes a RAG pipeline visible. A learner chooses or edits a source document, asks a question, and watches the app split the source into chunks, rank the chunks by similarity, assemble the prompt, compare a grounded answer with an unsupported baseline, and show quality checks.

## Why This Matters

The project turns an abstract AI concept into something inspectable. It helps learners understand why grounded answers are more trustworthy, how retrieval quality affects the final response, and what to check before trusting an AI-generated answer.

## Key Features

- Editable lesson scenarios and source text
- Chunking inspector with token estimates and top terms
- Deterministic local vector-style retrieval with cosine similarity
- Score bars and a 2D similarity plot
- Prompt assembly view showing system instruction, retrieved context, and user question
- Grounded answer with chunk citations beside an unsupported baseline
- Quality checks for retrieval confidence, evidence coverage, citation discipline, and hallucination risk
- Responsive browser UI that runs without API keys

## Architecture

The app uses Vite, React, and TypeScript. The RAG teaching pipeline lives in `src/lib/rag.ts`, the sample lessons live in `src/data/scenarios.ts`, and the interface is composed in `src/App.tsx` with styling in `src/styles/app.css`. Everything runs locally in the browser; there is no account system, hosted database, or external model dependency.

## Devpost Project Description

AI Basics Glassbox is a visual RAG debugger for people learning AI basics. Instead of hiding the answer behind a chat box, it shows the whole path from source text to grounded answer. A learner can edit a small knowledge base, ask a question, and inspect how the app chunks the source, ranks evidence with local cosine similarity, assembles the prompt, and compares a cited answer with an unsupported baseline.

The project is designed as a working proof of concept that runs locally without API keys. That keeps the demo reliable for reviewers and focuses the learning experience on the core mechanics: retrieval quality, evidence coverage, prompt context, and hallucination risk. The goal is simple: help a beginner understand why RAG can make AI answers more trustworthy, and what still needs to be checked before trusting the result.

## Built With

React, TypeScript, Vite, Vitest, Testing Library, lucide-react, CSS, local vector-style retrieval

## Known Limitations

- The retrieval model is deterministic and local for teaching purposes; it is not a production embedding model.
- The grounded answer is extractive and evidence-based rather than generated by a hosted LLM.
- The app uses bundled sample scenarios rather than file upload or persistent storage.
